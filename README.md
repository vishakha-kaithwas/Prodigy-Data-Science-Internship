# 🚀 Prodigy InfoTech – Data Science Internship Projects

This repository contains all tasks completed during my Data Science Internship at **Prodigy InfoTech**.  
Each task focuses on real-world data analysis, visualization, and machine learning techniques.

---

## 📌 Tools & Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab
- GitHub

---

## 📂 Tasks Overview

### 🔹 Task 01 – Data Visualization
Created visualizations to analyze distributions of categorical and continuous variables.

### 🔹 Task 02 – Exploratory Data Analysis (Titanic Dataset)
Performed data cleaning and EDA to uncover patterns affecting passenger survival.

### 🔹 Task 03 – Decision Tree Classifier
Built a machine learning model to predict customer purchase behavior using a Decision Tree algorithm.

### 🔹 Task 04 – Sentiment Analysis
Analyzed sentiment patterns in social media data to understand public opinion trends.

### 🔹 Task 05 – Traffic Accident Data Analysis
Analyzed accident data to identify patterns related to contributing factors and crash severity.
