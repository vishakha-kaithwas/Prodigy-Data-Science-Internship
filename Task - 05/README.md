# 🚦 Task 05 – Traffic Accident Data Analysis

## 🎯 Objective
Analyze traffic accident data to identify patterns in contributing factors.

## 📁 Dataset
Traffic crash dataset (public dataset used for analysis).

## 🛠 Tools Used
- Python
- Pandas
- Matplotlib

## 🔍 Analysis Performed
- Visualized total crashes by state
- Analyzed relationship between alcohol and speeding
- Examined crash totals vs insurance losses

## 📊 Key Insights
- Higher speeding rates correlate with increased crashes.
- Alcohol involvement significantly contributes to accidents.
- States with higher crashes show higher insurance losses.

---

This project demonstrates exploratory data analysis and factor-based accident pattern identification.
